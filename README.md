# Portfólio Review — Insany

Página de inscrição para o quadro de avaliação de portfólios do Gilberto Prado no YouTube. Mantém a identidade da página de talentos da Insany.

Site: https://gilberto-insany.github.io/insany-portfolio-review/

## Executar localmente

Use `python3 -m http.server 8080` na raiz deste repositório.

## Formulário

Formulário nativo do Notion incorporado por iframe. Cada envio entra na tabela privada do quadro. O site não armazena dados de participantes ou credenciais.

Campos: nome, link do portfólio, Instagram, vínculo como aluno(a) da Insany, nível (Júnior, Pleno, Sênior), áreas de atuação e autorização para exibir o trabalho no YouTube.

O formulário está configurado para respostas públicas, com campos obrigatórios e confirmação de envio em português.
